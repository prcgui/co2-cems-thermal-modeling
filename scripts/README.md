# Código de apoio

- `publication.py`: localização da raiz do projeto, leitura da chave EPA e gravação de saídas com caminhos relativos.
- `gerar_figuras_complementos.py`: figuras de 03A.05B e 03A.05C a partir dos resultados salvos, sem novo treinamento. Execute `python scripts/gerar_figuras_complementos.py` na raiz do projeto.

A sequência experimental está nos [notebooks](../notebooks).

- `caracterizar_monitoramento.py`: tabelas de indicadores horários e vigências dos planos, a partir dos [insumos de monitoramento](../references/monitoramento/). Execute `python scripts/caracterizar_monitoramento.py` na raiz.
