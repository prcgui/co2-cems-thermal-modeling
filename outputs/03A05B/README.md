# 03A.05B — Sensibilidade temporal das perdas

Resultados do [notebook 03A.05B](../../notebooks/03A_05B_incerteza_pareada_calendario.ipynb).

- `protocolo.json`: configuração dos blocos de calendário.
- `metricas_contextos.csv`: erros por contexto.
- `sensibilidade_blocos_calendario.csv`: diferenças pareadas e percentis por comprimento do bloco.
- `autocorrelacao_calendario.csv` e `contagens_blocos.csv`: dependência temporal e composição dos blocos.
- `sorteios_blocos.npz`: sorteios preservados.

A análise é exploratória; os percentis não têm cobertura nominal demonstrada.
